# 第 1 章插图

在正式工程根目录运行：

```bash
python3 scripts/figures/ch01/generate.py
```

脚本仅使用 Python 标准库，生成 `assets/01-ai-era-introduction/` 中的三张 SVG。文字、线条和图形均为可编辑的矢量对象；修改文字或位置后重新运行即可。

| 文件 | 内容 | 对应位置 |
| --- | --- | --- |
| `001-learning-around-questions.svg` | 围绕问题查找知识、实践并检查，AI 在各环节提供帮助 | 1.2 节，图 1.1 |
| `002-paper-and-knowledge.svg` | 完成论文涉及的工作、知识和回查过程 | 1.3 节，图 1.2 |
| `003-framework-transfer.svg` | 把思考方法用于新项目，并重新检查样本关系 | 1.4 节，图 1.3 |

三图为本书绘制的概念示意，没有引用外部图片。图 1.2 的小图表示工作类型；图 1.3 的字母表示个体身份，不表示实测数据或样本量建议。正文图注说明箭头与连线的含义。
