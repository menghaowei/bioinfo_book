先理解问题，再理解数据

生物信息学的本质，是使用信息学的手段解决生物学问题。会敲几行命令只是起点；知道数据从哪里来、每一步为什么这样处理，以及结果究竟能支持什么结论，才是我们希望一起建立的能力。

怎样使用这本书

第一次接触生物信息学时，可以按章节顺序阅读。已有命令行和编程基础的读者，可以从第 3—4 章核对概念，再进入自己关心的实战。第 1 章作为全书前言；从第 2 章起，各章先用“本章提要”介绍目标和内容。

实战中遇到统计概念时，可以回看第 11 章。原有 25 道基础问题及讲解已按主题并入正文，作为相关小节的知识问答；参考资料与素材说明集中放在附录。

宽屏同时显示全书目录、正文和本章目录。普通桌面保留右侧“本章目录”，点击顶部“全书目录”可打开章节列表；窄屏通过顶部按钮分别打开两种目录。目录标题均为单行显示，较长标题可以在目录内横向滚动查看。点击“搜索”可以检索全书正文。

核心知识：先理解这个概念

浅绿色框用于突出重要定义、原理和结论。读到这里时，可以停下来，用自己的话复述其中的意思。

注记核心知识｜比例的含义

比例表示某一部分在整体中所占的份额。例如，三项计数分别为 12、18、30，总和为 60；第一项所占的比例是 \(12 / 60 = 0.2\)，也就是 20%。

注意事项：核对条件与常见错误

浅黄色框提醒容易忽略的条件、常见错误或容易混淆的概念。使用相应方法前，先确认提醒是否适用于自己的情况。

警告注意｜比较比例前先看分母

看到“20%”时，要确认它表示哪一部分占哪个整体。比较两个比例之前，应先核对两者的统计范围。

示例与练习：把概念用起来

浅蓝色框提供算例、操作示例或练习。可以先独立思考，再对照其中的步骤和参考解答。

提示示例与练习｜计算第二项的比例

三项计数分别为 12、18、30。第二项占总和的多少？

参考解答： 总和为 60，第二项所占比例为 \(18 / 60 = 0.3\)，即 30%。

拓展阅读：按需深入了解

灰色拓展框提供补充背景或进阶解释，默认收起。点击下面的标题可以展开阅读，再次点击可以收起。

注记拓展阅读｜相同的比例可以对应不同的数量

\(12 / 60\) 和 \(120 / 600\) 都等于 20%。因此，解释一个比例时，同时了解对应的实际数量，有助于看清数据的背景。

正文强调与引用：辨认文字的用途

  • 加粗标出需要留意的词语或结论，例如：比较数据之前，先确认比较对象和统计范围。
  • 斜体用于轻量强调，例如：先写下自己的判断，再阅读解答。
  • 行内代码用于软件名、命令、参数、变量和文件名，例如 Python、counts 和 sample.fastq.gz，方便与普通叙述区分。

代码高亮与重点行：跟着解释读代码

代码框顶部标明语言或用途。框内不同颜色帮助辨认关键字、字符串、数字和注释；浅绿色整行背景和左侧标记指出当前需要特别关注的代码。

整行底色只在有对应讲解时出现。没有整行底色的代码同样保留语法着色，可结合前后说明阅读。

下面是一段 Python 示例。即使暂时不会编程，也可以先观察：以 # 开头的文字是注释，if 是关键字，引号中的文字是字符串。左侧行号用于定位；第 3 行计算总和，第 6 行计算并显示第一项所占的比例，这两行被突出显示。

# 三项示例计数
counts = [12, 18, 30]
total = sum(counts)
if total > 0:
    print("计数总和：", total)
    print("第一项所占比例：", counts[0] / total)

可以点击“复制”取得代码，复制结果保留代码本身的缩进和换行，不含界面行号；点击“展开代码”可放大阅读，点击“关闭”或按 Escape 返回。较长的行可在代码框内横向滚动。行号和重点行按讲解需要设置，并非每段代码都有。
